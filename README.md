# Windows 本地的计划安排与排版清单工具，可自动排版生成文件以便打印。C# + WinUI 3，中文界面，离线使用。

## 当前状态

当前正式便携版为 `v1.1.3`。构建后可在 `release/v1.1.3/` 内运行 `ToDoList.exe`。正式版无预置测试数据，首次打开为空白计划。构建、发布和版本管理规则见 [WORKFLOW.md](WORKFLOW.md)。

## 功能

### 日历簿与计划编辑

- 创建、重命名和删除多个日历簿。每本日历簿独立保存与导出计划，重开程序时恢复上次打开的日历簿。删除日历簿及其计划前会要求确认。
- 在月历中点击日期，或用左右箭头切换。今天以圆角细框标记。右侧编辑区默认较宽，拖动分隔线后会记住宽度。
- 每天可填写多行计划和自由文本的预计用时。拖动行首序号可调整顺序，导出时沿用该顺序。
- 编辑后等待 500 毫秒自动保存，切换日期、点击「完成」或正常关闭时立即保存。状态栏显示最近保存时间，例如 `已保存 · 2026.11.21 09:56:22`。SQLite 事务保存失败时会保留编辑内容，并阻止切换或关闭。

### 批量操作

- 「批量设置」可把同一条计划及预计用时添加到当前日历簿的多个日期。可逐日点选，也可多次加入日期范围。
- 「删除批量添加」可删除同一批次中仍未修改的计划，并显示实际会删除的日期。后来单独修改过的条目会保留。
- 「批量删除」列出所选日期的计划，勾选后可一次删除多条。

### 导出与打印

- 点击「完成」进入导出页，可逐日勾选或多次加入日期范围。跨过未选日期时，界面会用逗号分隔各段，文档标题和默认文件名也采用同样的日期范围，例如 `2026.11.16-11.20 ，11.22  to-do-list`。
- 默认文件名随日期选择更新，也可自定义或重置。程序会记住最近使用的导出文件夹。
- 可同时选择 Word（`.docx`）、PDF（`.pdf`）和图片（`.jpg`）。JPG 沿用 PDF 排版，有几页就生成几张图。Word 和 PDF 嵌入随程序分发的中文字体，导出无需安装 Microsoft Office。
- 使用 A4 纵向排版，26 磅标题居中，按日期和星期分组，预计用时列于右侧。默认显示供打印勾选的空心方框，也可关闭，让计划文字靠左对齐。
- 默认勾选「包含空白日期，留出手写空间」。每个空白日期留三行无下划线的手写空间，应用会记住上次的勾选状态。
- 同时导出多种格式时，程序先生成全部临时文件。若替换已有文件失败，会尝试恢复原文件。

## 便携数据

发布目标为 Windows x64 自包含文件夹，基线系统 Windows 10 2004 / Windows 11。运行依赖、中文字体和 Visual C++ CRT 随文件夹分发；已验证本机从不同目录启动，其他电脑仍需实际验收。

```text
release/v1.1.3/
  ToDoList.exe
  Assets/Fonts/         中文字体及其许可证
  Data/plans.db         首次运行时创建，存放计划、顺序和界面设置
  Data/plans.backup.db  打开应用时生成的上一会话完整备份
  Exports/              默认导出目录
  …                     .NET、WinUI、SQLite、Visual C++ 自包含运行依赖
```

所有内部路径基于 `AppContext.BaseDirectory`，不依赖启动目录，不包含开发电脑的盘符。关闭程序后移动整个版本文件夹即可带走数据。应放在当前用户可写的目录，避免 Program Files 或只读盘。文件锁阻止同一便携目录被多个窗口同时编辑。

每次交付新版本使用递增目录 `v0.0.1`、`v0.0.2`……，不覆盖旧版，不生成 ZIP。同一次交付前的修错重试保留版本号。新版本不自动复制用户数据，沿用计划时请先关闭两个版本，再自行将旧版 `Data/` 复制到新版。

测试发布版本可包含带标记的虚构计划。从 `v1.0.0` 起随发布附上 `删除测试数据.cmd`，供手动迁入旧测试版数据后使用。脚本仅清理未修改的示例记录，保留用户修改或新增的计划，清理成功后删除自身。

默认导出位置为应用文件夹内的 `Exports/`。应用会优先使用上次选择的文件夹，如果该位置不可用，就回到默认目录。数据库和导出文件不提交到 Git。异常断电或强制结束进程可能丢失尚在 500 毫秒等待期内的输入。

## 开发环境与依赖

- .NET 10 SDK 或支持目标框架的更新 SDK。
- Visual Studio / Build Tools 的 WinUI 3 C# 与 Windows SDK 构建组件。
- 稳定版 Windows App SDK 1.8、Microsoft.Data.Sqlite 10、Open XML SDK 3、MIT 授权的 PDFsharp/MigraDoc 6.2.4、CommunityToolkit.Mvvm 8，具体版本固定于项目文件。
- 首次还原依赖需要连接 NuGet。

经批准后，可在项目根目录执行：

```powershell
dotnet build ToDoList.sln -c Debug -p:Platform=x64
dotnet publish src/ToDoList.App/ToDoList.App.csproj -c Release -p:Platform=x64 -r win-x64 --self-contained true -p:Version=0.0.1 -o artifacts/publish-candidate
```

上述 publish 命令仅生成候选程序。正式整理到全新的 `release/v版本号/` 前还须补齐 app-local Visual C++ CRT、许可证和发布元数据，并检查所有依赖。不能只复制一个 exe；必须复制完整版本文件夹。Word 在不同编辑软件中重新排版时，分页可能与 PDF 不同。特殊字符（例如少见表情）是否可显示取决于字体覆盖范围。
